# Manjara International School Website

A modern, responsive, and user-friendly website developed for **Manjara International School** to provide students, parents, staff, and visitors with easy access to information about the school, admissions, academics, facilities, activities, achievements, and other important resources.

## 🌐 Project Overview

The Manjara International School website is designed to provide a professional digital presence for the school while making important information easily accessible.

The website includes dedicated sections for:

* 🏫 About the School
* 👨‍🏫 Managing Team
* 🎓 Admissions
* 📚 Curriculum
* 🌱 Educational Approach
* 🏅 Awards & Achievements
* 🏢 School Facilities
* 🌍 Learning Environment
* 👩‍🎓 Student Journey
* 🤝 Community Initiatives
* 📰 News & Updates
* 🖼️ Gallery
* 🎓 Alumni
* 💼 Careers
* ❓ Frequently Asked Questions
* 📍 School Location
* 📞 Contact & Enquiry
* 💬 Chairman/President Messages

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/dhrutimahadik5106/Manjara_International_school_website.git
```

### 2. Navigate to the project

```bash
cd Manjara_International_school_website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will start on the local development server. Open the URL displayed in your terminal, usually:

```text
http://localhost:5173
```

## 🏗️ Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
